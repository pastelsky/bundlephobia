# Anti-slop provenance

The vendored rules in this directory come from
[`dmmulroy/anti-slop`](https://github.com/dmmulroy/anti-slop), copied from
upstream commit `c44ef22` on 2026-09-15.

`src/` is vendored as project-owned source so the repository can review and
adapt the rules without depending on an unpublished npm package. Keep the
upstream revision and any local policy changes documented here when updating
the rules.
