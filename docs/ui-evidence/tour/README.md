# UI foundation visual tour

Captured against the local development server with the shared UI foundations
enabled. The sequence records the actual controls in their screen context,
including form entry, package selection, asynchronous scan results, alternate
sort state, detail/error state, footer, and mobile breakpoints.

| Range | Coverage                                                                     |
| ----- | ---------------------------------------------------------------------------- |
| 01–03 | Desktop component catalog and open popover                                   |
| 04–06 | Homepage search, footer, and populated search field                          |
| 07–12 | Scan upload, URL form, populated form, package selection, and selection edit |
| 13–15 | Scan results while calculating, scrolled list, and size sort                 |
| 16–18 | Package-detail route and lower-page states                                   |
| 19–22 | Original mobile homepage, populated search, scan, and component catalog      |
| 23–25 | Revised responsive nav, scan-selection gutter, and padded result toggles     |
| 26–27 | Light-mode catalog and homepage                                              |
